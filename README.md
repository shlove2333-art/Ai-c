# Card Dungeon 🃏⚔️

덱빌딩 RPG — Slay the Spire 스타일의 카드 전투 게임

## 실행 방법

```bash
pip install pygame
python main.py
```

## 게임 방법

- **숫자키 1~9** 또는 **마우스 클릭** 으로 카드 선택
- **공격 카드**: 카드 선택 후 적 클릭
- **스킬/파워 카드**: 카드 선택 후 빈 공간 클릭
- **E키** 또는 **End Turn 버튼** 으로 턴 종료

| 카드 | 코스트 | 효과 | 희귀도 |
|------|--------|------|--------|
| Strike | 1 | 6 데미지 | 일반 |
| Bash | 2 | 8 데미지 + 취약 2 | 일반 |
| Defend | 1 | 방어 5 | 일반 |
| Iron Wave | 1 | 방어 5 + 5 데미지 | 비일반 |
| Whirlwind | 1 | 5 데미지 × 3 | 비일반 |
| Inflame | 1 | 힘 +2 | 비일반 |

| Limit Break | 1 | 힘 2배 | 희귀 |
